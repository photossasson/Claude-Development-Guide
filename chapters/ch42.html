Glossary

מילון מונחים של המדריך: 108 מונחים באנגלית, מסודרים לפי א"ב אנגלי, כל אחד עם הסבר קצר בעברית, דוגמה מעשית והפניה לפרק שבו הוא מוסבר לעומק. המילון הוא המקום שקובע איך המדריך משתמש בכל מונח; אם ניסוח בפרק כלשהו נראה סותר, הניסוח כאן גובר.

איך להשתמש במילון

המונח האנגלי הוא הקנוני: כך הוא נכתב בתיעוד הרשמי, כך הוא מופיע בממשק של Claude Code, וכך תחפשו אותו בגוגל, ב-GitHub וב-/help. המדריך אינו מתרגם מונחים טכניים לעברית ואינו מתעתק אותם לאותיות עבריות; ההסברים בעברית, המונחים באנגלית. כל שורה במילון בנויה מארבעה חלקים:

  • Term: המונח באנגלית, בתא מיושר לשמאל, כולל צורות משנה נפוצות בסוגריים.
  • הסבר: משפט עד שלושה, במשמעות המדויקת שבה המדריך משתמש. כשמונח דומה מופיע במוצר אחר של Anthropic (למשל Skills ב-Claude Code לעומת Skills באפליקציות Claude), ההסבר מציין את הגבול.
  • דוגמה: פקודה, קובץ, נתיב או משפט שימוש קצר.
  • פרק: היכן ההסבר המלא. חיפוש מהיר: Ctrl+F בדפדפן על המונח האנגלי.

תרגיל

תרגיל 42.1: מבחן הבחנה בין מונחים

לכל זוג מונחים, כתבו במשפט אחד את ההבדל המעשי ביניהם, והפנו לערך במילון שממנו לקחתם את ההגדרה: (1) Skill מול Hook; (2) MCP server מול Connector; (3) Subagent מול Background session; (4) Checkpoint מול Git commit; (5) Permission mode מול Permission rule. בסוף, מצאו במילון מונח אחד שאתם משתמשים בו בעברית מתועתקת בצוות, והחליטו איך תכתבו אותו מעכשיו.

פתרון מוסבר

(1) Skill הוא הוראות שנטענות לפי דרישה ו-Claude מחליט אם ליישם; Hook הוא קוד דטרמיניסטי שרץ תמיד באירוע מוגדר. (2) MCP server הוא כל שרת פרוטוקול שאתם מגדירים בעצמכם; Connector הוא שרת MCP מנוהל שמגיע דרך claude.ai עם בקרות ארגוניות, ונטען ב-Claude Code רק עם התחברות מנוי. (3) Subagent רץ בתוך ה-Session שלכם ומחזיר תוצאה לשיחה; Background session הוא Session שלם שרץ מנותק מה-Terminal תחת Daemon. (4) Checkpoint מכסה רק עריכות דרך כלי הקבצים של Claude ונשמר מקומית לזמן מוגבל; Git commit מקבע את כל מצב הקבצים ומשותף. (5) Permission mode קובע את ברירת המחדל לכל הכלים; Permission rule (allow, ask, deny) חלה על כלי או דפוס ספציפי וגוברת על המצב. אם התקשיתם באחד הזוגות, זה הפרק שכדאי לקרוא שוב: 21 ו-22, 23 ו-24, 25 ו-33, 19, 18.

סיכום

המילון הוא שכבת המונחים המשותפת של המדריך: כל ערך נותן הגדרה קצרה, את המונח באנגלית כפי שהוא מופיע בתיעוד הרשמי, ואת הפרק שמרחיב. הטבלה האחרונה מתעדת שמות ישנים שהוחלפו, כדי שלא תתבלבלו כשתפגשו אותם במאמרים או בפרויקטים ותיקים. השתמשו בו יחד עם דף העזר: שם מה מקלידים, כאן מה זה אומר.

# Issue Tracker MCP (Asana + תבנית גנרית)

## הסבר שדות

- asana: הדוגמה הרשמית מהתיעוד לשרת SSE. SSE מיושן (Deprecated); העדיפו HTTP כשהספק מציע.
- your-tracker: תבנית מסומנת במפורש; הדומיין example לא יתחבר. הציבו כתובת אמיתית ב-TRACKER_MCP_URL או החליפו ידנית. כתובות Linear/Jira לא אומתו מהסביבה (F-012).

## אבטחה והרשאה מינימלית

אימות OAuth: claude mcp login asana או /mcp ואז Authenticate. אין סודות בקובץ. תיאורי משימות הם משטח Prompt Injection; השאירו כלל ask על השרת.

## הבדלי מערכות הפעלה

זהה בכל מערכות ההפעלה.

## התקנה

העתיקו את .mcp.json לשורש הפרויקט (או מזגו לקיים), הגדירו את משתני הסביבה, ופתחו Session חדש. בדקו עם `claude mcp list`. מקור: פרק 23 במדריך; נבדק 28.07.2026.
